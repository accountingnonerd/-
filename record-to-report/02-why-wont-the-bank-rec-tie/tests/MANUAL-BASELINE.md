# The same work by hand

A quarter's catch-up for one checking account (about 60 bank lines, 100 book entries), done the usual
way in the ledger's reconcile screen and Excel, when it does not tie at the first try. Minutes are
estimates, not measurements.

| Step | By hand | Minutes |
|---|---|---|
| 1 | Download the statements; export the ledger; set up the first month's reconciliation | 10 |
| 2 | Tick off cleared items, three months in turn, against each statement | 45 |
| 3 | The difference is not zero: compare both lists line by line to find the transposed check, the deposit entered twice, the refund entered the wrong way | 30 to 90 |
| 4 | Work out which checks from before January were still outstanding (last year's reconciliation report, if anyone kept it) | 15 |
| 5 | List the outstanding items with their ages, note the stale ones, write the entries and the questions | 20 |
| | **Total** | **about 2 to 3 hours** |

The tool does steps 2 to 5's searching in a second and drafts the lists and entries. What stays with
the accountant: checking what was read, deciding whether each odd pair is the same transaction,
treating the bank-only items, and what to do with stale checks.
