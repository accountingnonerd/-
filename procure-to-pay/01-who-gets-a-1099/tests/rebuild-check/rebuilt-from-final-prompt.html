Who gets a 1099?

  • What it adds. Accounting software's 1099 report counts only vendors someone flagged for 1099. This reads every payment, so it also finds vendors nobody flagged, one vendor typed several ways, and checks entered twice.
  • Which file. All payments for the tax year, one line per check or charge (.csv or .xlsx).
  • Which rule. $2,000 for 2026 payments; $600 for 2025 and earlier.
  • Private. The file never leaves this computer.
